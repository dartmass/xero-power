# Xero Power デモ動画 撮影手順

構成: **Free → Solo Pro → Practice Pro**。編集はFCPX。

原則3つ。

1. **プラン切替は2回だけ**（Free → Solo → Practice）。戻らない
2. **消費される素材は各プランの最後**（照合すると明細が消える、承認するとBillが消える）
3. **1プラン1ファイルの長回し**。機能の区切りは「3秒静止＋マウスを画面隅へ」

---

## Phase 0 — 撮影前の準備（一度だけ・30分）

### 画面まわり

- [ ] Chromeのブックマークバーを隠す（Cmd+Shift+B）
- [ ] **他のタブを全部閉じる**。QuickSoldCheckなど他プロジェクトのタブが写らないように
- [ ] ツールバーの他拡張アイコンを隠す（Xero Power以外をピン留め解除）
- [ ] Chromeウィンドウを固定サイズに。1440×900程度。撮影中にリサイズしない
- [ ] Xeroのズームを110%前後に。動画は縮小されるので、静止画より大きめが読める
- [ ] macOSの通知を「集中モード」で止める。**ただしPhase 3の通知デモの直前に解除する**
- [ ] デスクトップの壁紙・Dockに個人情報が写らないか確認

### キー表示（重要）

キーボード操作が売りの拡張なので、**押したキーが見えないと何も伝わりません**。

どちらか決めてから撮る。後から足すのは高くつく。

- **A案（推奨）**: キーストローク表示アプリを常駐させて撮る
- **B案**: 素で撮ってFCPXでキーのテロップを都度入れる（見た目は良い・編集が重い）

B案なら、撮影中に**キーを押す瞬間だけ1秒止める**。テロップを置く隙間になる。

#### A案を選ぶ場合

macOSでは KeyCastr（無償・オープンソース）が定番。ほかに有償のものもある。

**画面収録は画面に合成されたものを撮るので、常駐アプリの浮動ウィンドウもそのまま入る。**
ただし焼き込みなので、あとから位置も見た目も変えられない。**本番前に10秒だけ試し撮りして、
再生して確認すること。**

設定で決めておくこと:

- **表示位置** — 画面の左下。Xeroの操作対象と、FCPXでテロップを置く上部を避ける
- **表示時間** — 1.5〜2秒。既定は短いことが多く、動画では読み切れない
- **文字サイズ** — 大きめ。動画は縮小されて配信される
- 初回起動時に「アクセシビリティ」または「入力監視」の許可を求められる

**Bank Recの緑のヒントバーとは重複する。** あのバーは拡張自身がキーを表示しているので、
Phase 1の 1-9 〜 1-11 では二重に出る。邪魔なら該当カットだけ常駐を切ってもよいが、
「押した」ことが伝わるのは常駐側なので、基本は出したままでよい。

Ctrl+K のパレット（1-1〜1-3）には拡張側の表示が無いので、**ここは常駐が必須**。

### Xero側のデータ準備

Demo Company (Global) で以下を先に作っておく。撮影を止めて作ると流れが切れる。

- [ ] **Bills → Awaiting approval に5件以上**（現在6件。通知デモで増やす分の余裕）
- [ ] **Draft Bill を3件**用意
  - 1件目: Region（tracking）だけ空欄 — Practice Proのガード用
  - 2件目: Description だけ空欄 — 同上
  - 3件目: 両方空欄 — 同上
- [ ] **Draft Invoice を1件**（Approve既定の説明用。承認はしない）
- [ ] **銀行口座に未照合の明細が10件以上**（足りなければDemo Companyをリセット）
- [ ] **Find and recode** で Description列を含む結果が出る検索条件を1つ決めておく
- [ ] **Bills を25件表示**にして2ページ以上にする（Solo Proのページ送り用）
- [ ] **組織が3つ以上**（現在 aaa / bbb / Demo Company）

### 拡張側

- [ ] `chrome://extensions` で🔄
- [ ] **Freeから始める**。Service Worker → Console:
  ```js
  chrome.storage.local.remove(['xp_pro','xp_plan','xp_pro_owner','xp_license_local_qa'])
  ```
- [ ] Settingsで `Free` 表示を確認
- [ ] **組織カラーを事前に設定**（aaa・bbb の2つ。Freeの上限デモに使う）

### 3-8 の撮り方

一発勝負になりやすいので手順を固定する。

1. `Awaiting approval` を開いて件数を記録させる（例: 6件）
2. **録画を回したまま** 別タブでDraft Billを `Submit for approval`
3. `Awaiting approval` のタブに戻って再読み込み
4. 通知バナーが出る → **クリック** → Xeroの一覧が新規タブで開く

**通知は画面の右上に出る**。Chromeウィンドウをそこに被せないように、あらかじめ左寄せにしておく。

失敗したらもう1件Submitすればやり直せる。**準備したDraft Billを2件は残しておく**。

## 編集の並び（FCPX）

```
つかみ    1-4（手動で何クリックか） → 1-2（Ctrl+Kで一発）
Free      1-1 1-3 1-5 1-6 1-7 1-9 1-10 1-11
          ↓ 1-8（3組織目がロック）で引く
Solo Pro  2-1 2-2 2-3 2-4 2-5 2-6
          ↓
Practice  3-1 3-2 3-4 3-5 3-6 3-7 3-8
```

3-3は3-2と内容が重なるので、尺が長ければ落とす。**3-5は落とさない** — 承認だけ止めてSaveは通す、が製品の思想そのもの。
